LEVEL UP GEARS — free website starter

FILES
- index.html: complete mobile-friendly storefront.

BEFORE PUBLISHING
1. Open index.html in a text editor (Notepad is fine).
2. Find WHATSAPP_NUMBER and replace 91XXXXXXXXXX with your WhatsApp number:
   India format: 91 followed by your 10-digit number, digits only.
3. Find the PRODUCTS array and replace the five starter examples with your real products,
   actual prices, descriptions and icons. Keep the JavaScript object format.
4. Save and open index.html in Chrome to test it.
5. Test the order form with your own details. WhatsApp opens with a pre-filled message;
   the customer must press Send.

FREE HOSTING WITH GITHUB PAGES
1. Create/sign in to https://github.com/
2. Create a new public repository named level-up-gears (or any name).
3. Upload index.html to the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for the published URL shown in Settings → Pages.

IMPORTANT
- No paid domain or hosting is required for this static website.
- The site does not store customer data, provide a cart, process payments, or automatically
  send orders to suppliers. It hands the order message to WhatsApp.
- Confirm stock, shipping, returns, final price and payment safely with each customer.
- Never publish customer personal information or ask for unnecessary sensitive data.
